## 🚀 Utilisation

### Installation

```bash
# Lancer l'interface moderne
python nitrite_v13_modern.py
```

### Navigation

1. **Sélectionner une page** via la barre latérale :
   - 📦 **Applications** : Installer des logiciels
   - 🛠️ **Outils** : Accéder aux outils système

2. **Page Applications** :
   - Rechercher une application
   - Sélectionner les apps désirées
   - Cliquer sur le bouton 🌐 pour accès web
   - Cliquer sur "INSTALLER" pour démarrer

3. **Page Outils** :
   - Parcourir les sections
   - Cliquer sur un outil pour l'exécuter
   - Les commandes système s'exécutent automatiquement
   - Les liens web s'ouvrent dans le navigateur

### Raccourcis

- **Recherche** : Commencer à taper pour filtrer
- **Scroll** : Molette de souris ou barre de défilement
- **Sélection** : Clic sur checkbox ou nom d'application
- **Web** : Clic sur icône 🌐 pour ouvrir le site

## 🔧 Configuration Technique

### Prérequis
- **OS** : Windows 10/11
- **Python** : 3.8+ (pour version script)
- **RAM** : 4 GB minimum (8 GB recommandé)
- **Résolution** : 1400x900 minimum

### Dépendances
- `tkinter` - Interface graphique
- `Pillow` - Gestion d'images
- `requests` - Téléchargements
- `json` - Configuration

### Structure
```
Nitrite-V.13-Beta-Portable-/
├── nitrite_v13_modern.py          # Lanceur principal
├── src/
│   ├── gui_modern_v13.py          # Interface moderne
│   ├── profiles_manager.py        # Gestionnaire de profils
│   ├── installer_manager.py       # Gestionnaire d'installation
│   └── [autres modules...]
├── data/
│   ├── programs.json              # Base de données apps
│   └── config.json                # Configuration
└── assets/
    └── [icônes et images]
```
